## About

Senior Mobile Engineer specializing in React Native and TypeScript, with experience building and evolving mobile products across fintech, banking, telecom, e-commerce, and superapp environments.

I work across the full software development lifecycle, from architecture and implementation to testing, observability, CI/CD, and production releases.

My experience includes scalable MVVM architectures, BFF integrations, critical financial flows such as Pix, payments and billing, secure authentication with Auth0, and native iOS and Android integrations.

My main stack includes React Native, TypeScript, Expo, Redux, React.js, and Next.js. I also have experience with Node.js, PHP/Laravel, Jest, Docker, GitHub Actions, Bitrise, Harness, Sentry, Datadog, Mixpanel, and Kibana.

I enjoy working on complex engineering problems, improving software quality, and building reliable solutions that scale.
