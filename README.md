### About

Senior Mobile Engineer specializing in React Native and TypeScript, with experience designing, building, and scaling mobile applications across fintech, banking, e-commerce, and digital platforms.

I work across the entire software development lifecycle, from technical architecture and implementation to testing, performance optimization, observability, CI/CD, and production releases.

My experience includes designing scalable MVVM architectures, building complex financial features such as Pix, payments, billing, account opening, and investment flows, developing cross-platform applications with React Native and Expo, and integrating native iOS and Android capabilities.

I also have experience with secure authentication using Auth0, automated testing with Jest, application monitoring with Sentry, Datadog, Mixpanel and Kibana, and CI/CD pipelines with Bitrise, Harness, and GitHub Actions.

I enjoy solving complex engineering problems, improving existing architectures, and building reliable products that deliver meaningful value to users.
